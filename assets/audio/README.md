# Audio Assets Directory

Place your audio files here when ready:
- `surprise_unlocked.mp3` (e.g., Abhi Toh Party Shuru Hui Hai)
- `birthday_celebration.mp3` (e.g., London Thumakda)
- `photo_slideshow.mp3` (e.g., Gallan Goodiyaan)

Note: If no audio file is provided, the application will automatically fall back to silent mode or soft Web Audio synthesizer chimes without throwing errors.
